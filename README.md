# Student Teacher Portal

This is a simple frontend project made using React.

The project is a basic portal for students and teachers.

There are two types of users:

- Student
- Teacher

The project uses dummy data and does not have a backend or database.

## Features

The project has the following basic features:

- Student and teacher login
- Dashboard
- Profile page
- Settings page
- Change user name
- View students and teachers

The dashboard is available for both students and teachers.

## Technologies

The project uses:

- React
- JavaScript
- HTML
- CSS
- Vite

## Project Structure

The main project files are organized into different folders.

- `components` contains reusable components.
- `pages` contains the main pages.
- `data` contains the dummy user data.
- `App.jsx` connects the different parts of the application.
